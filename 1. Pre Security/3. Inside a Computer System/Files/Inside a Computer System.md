Computer : har computer ke andar kuchh parts hote hai or har parts ka apana kuchh kam hota hai. jisase hamara computer kam karata hai 

### Mother board : 
Mother board hamare computer ka aisa part hai jo sare components ko jodkar rakhata hai 

### Hard Disk , SSd Card
Hard disk hamare computer ka permanently storage hota hai , isi ke andar file padi huyi hoti hai , lekin ye thoda slow hota hai

>SSD : ssd card hard disk se fast hota hai , or ye bhi permanently storage hai computer ka

### Ram
Ram 1 temporary storage hoti hai computer mai ye hdd ya ssd se bahut fast hoti hai , jab hamara computer boot hota hai tab ye use hoti hai or jab band ho jata hai tab isaka data clear ho jata hai 

### CPU
COMPUTER mai cpu ka kam hota hai fastest calculation karana processing karana 

### Network Adapter
Network Adapter ka bahut bada kam hota hai computer m kyu ki yahi 1 computer se dusare computer ke bich batchit karata hai 

### Power Supply
Power Supply ka kam hota hai har 1 components ko supply dena

### Graphics card
Graphics card ka kam hota hai , jo hamare screen par dikh raha hai usaka or achha karna visualization achha karana , image graphics ko achha karana 

### Input Output
ye hamara actual monitor hota hai jo kuchh bhi iske upper dikhata hai or ya to input ho sakta hai ya output
